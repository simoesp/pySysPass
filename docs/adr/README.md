# Architecture Decision Records (ADRs)

This directory documents significant architectural decisions for pySysPass.

Each ADR:
- Records a decision that was hard to reverse
- Explains why that decision was made (the trade-offs considered)
- Is referenced from other docs to maintain traceability

## Decision numbering

ADRs are numbered sequentially (0001, 0002, ...) to maintain a stable reference.

## Template

See `0000-template.md` for the ADR format and required sections.
